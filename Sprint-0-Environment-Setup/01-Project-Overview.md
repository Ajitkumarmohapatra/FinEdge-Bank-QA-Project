# Project Overview

## Project Name

**FinEdge Bank QA Project**

---

## Project Description

FinEdge Bank QA Project is a complete End-to-End Software Testing project developed for learning and demonstrating Manual Testing, API Testing, Database Testing, and Automation Testing using a Core Banking Application built on Apache Fineract and Mifos.

The project follows an Agile Sprint-based approach where every module is tested from Requirement Analysis to Test Execution.

---

## Project Objectives

- Learn real-world Software Testing
- Perform Manual Testing
- Perform API Testing using Postman
- Validate Database using PostgreSQL
- Automate test cases using Selenium WebDriver
- Manage project documentation using GitHub
- Follow Agile Scrum methodology

The project covers the following testing activities:

- UI Testing
- API Testing
- Database Validation
- Automation Testing
- Regression Testing
- Smoke Testing
- Sanity Testing
- Bug Reporting
