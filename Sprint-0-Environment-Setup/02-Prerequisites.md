# Prerequisites

## Objective

This document lists all software, tools, and system requirements required before setting up the FinEdge Bank QA Project.

---

# Hardware Requirements

| Component | Minimum Requirement |
|-----------|---------------------|
| Processor | Intel Core i5 or equivalent |
| RAM | 8 GB (16 GB Recommended) |
| Storage | 20 GB Free Space |
| Internet | Required |

---

# Operating System

- Windows 11 (Recommended)
- Windows 10 (Supported)

---

# Required Software

| Software | Purpose |
|----------|---------|
| Java JDK 21 | Backend Runtime |
| Git | Version Control |
| Docker Desktop | Run Apache Fineract Services |
| PostgreSQL | Database |
| Node.js (LTS) | Angular Runtime |
| Angular CLI | Run Mifos Web Application |
| VS Code | Code Editor |
| Postman | API Testing |
| Google Chrome | Browser Testing |
